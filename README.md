# Wild Rift Jungle Draft Picker

Mobile-first draft helper for choosing the best jungle pick from a personal champion pool.

## Features

- Pick up to 4 teammates and 5 enemies.
- Instant top-3 jungle recommendations.
- Editable champion pool.
- Personal ability/comfort weighting.
- Editable meta-strength weighting.
- Draft-fit, ability, and meta scoring weights.
- Saves settings locally on the device.
- Installable/offline-capable PWA when served over HTTPS.

The scoring model is a practical draft heuristic rather than a claimed precise matchup win-rate model.
